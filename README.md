#  diagnosticador-de-red

¡Hola! 👋 ¡Bienvenido a la Herramienta de Diagnóstico de Red!

Esta es una pequeña pero poderosa aplicación de línea de comandos diseñada para ayudarte a diagnosticar y solucionar problemas comunes de red en sistemas Windows. ¡Es como tener una navaja suiza para tu conexión a internet! 🛠️

---

## 🚀 ¿Qué puedes hacer con esta herramienta?

Aquí tienes un resumen de las funcionalidades que incluye:

*   **Configuración IP** 📄: Revisa todos los detalles de tu conexión, como tu dirección IP, la puerta de enlace y los servidores DNS.
*   **Liberar y Renovar IP** 🔄: ¿Tu conexión se siente un poco "rara"? A veces, simplemente liberar y renovar tu dirección IP puede solucionar el problema.
*   **Ping** 핑: Envía una pequeña señal (un "ping") a cualquier sitio web o servidor para ver si está en línea y cuánto tarda en responder.
*   **Tracert (Trazar Ruta)** 🗺️: Descubre el camino exacto que toman tus datos a través de internet para llegar a su destino. ¡Es como un mapa GPS para tus paquetes de datos!
*   **Medir Latencia y Paquetes Perdidos** 🔬: Realiza una prueba más profunda para comprobar la calidad de tu conexión, midiendo la velocidad de respuesta (latencia) y si se pierden datos por el camino.
*   **Ver Dispositivos Conectados** 💻: Muestra una lista de todos los dispositivos que están conectados a tu misma red local.

---

## 📋 Cómo Empezar

¡Usar la herramienta es súper fácil! Sigue estos pasos:

1.  **Descarga el archivo**: Asegúrate de tener el archivo `net_diag.bat` en tu ordenador.
2.  **Abre una consola de comandos**:
    *   Puedes hacerlo pulsando la tecla de **Windows + R**.
    *   En la ventana que aparece, escribe `cmd` y pulsa **Enter**.
3.  **Navega hasta la carpeta**: Usa el comando `cd` para moverte a la carpeta donde guardaste el archivo. Por ejemplo, si lo guardaste en el Escritorio, escribirías:
    ```
    cd Desktop
    ```
4.  **Ejecuta la herramienta**: Una vez en la carpeta correcta, simplemente escribe el nombre del archivo y pulsa **Enter**:
    ```
    net_diag.bat
    ```
5.  **¡Listo!** 🎉 Se abrirá un menú a todo color donde podrás elegir la opción que necesites simplemente escribiendo el número correspondiente.
